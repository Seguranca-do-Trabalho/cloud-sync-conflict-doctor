# ADR-0001 — Language and stack: C#/.NET 8

- **Status:** Accepted
- **Date:** 2026-08-22
- **Decided by:** Orchestrator (card T01), following house standard (SMB Speed Doctor)

## Context

The product is local-first for Windows, with a real consumer-grade GUI, CLI from day one, high-performance scanner over Windows filesystem, cache in SQLite, and mandatory deterministic tests. The author already maintains another product in the same requirements family (SMB Speed Doctor) in C#/.NET 8 with a Core/Cli/Gui/Tests solution.

## Decision

C#/.NET 8, multi-project solution:

```text
CloudSyncConflictDoctor.sln
├── src/Doctor.Core        (scanner pipeline, domain model, report — zero UI)
├── src/Doctor.Cli         (conflictdoctor scan <path> [--json] [--quiet])
├── src/Doctor.Gui         (main product GUI)
└── tests/Doctor.Tests     (TDD; determinism, placeholders, quarantine)
```

## Consequences

- BLAKE3 via `Blake3` package (NuGet) — explicit algorithm in report schema (`algorithm = BLAKE3`, `hash_version = 1`, `report_schema_version = 1`).
- SQLite via `Microsoft.Data.Sqlite`.
- Level 0 enumeration will use `System.IO.Enumeration.FileSystemEnumerable` (metadata already present in enumeration) and P/Invoke for `FILE_ATTRIBUTE_*` when needed; the Windows-native layer (FindFirstFileEx/LARGE_FETCH, IOCTL_STORAGE_QUERY_PROPERTY) is isolated behind an interface for the windows-native agent to implement without affecting contracts.
- Determinism by byte-wise path sorting before any output.
