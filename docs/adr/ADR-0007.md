# ADR-0007 — Concurrency: configurable pool with abstracted media detection

- **Status:** Accepted
- **Date:** 2026-08-22
- **Decided by:** Architect (card T01)

## Context

§11 mandates separating decision (serial) from reading (parallel), enumeration with a preference for one thread per volume, configurable and calibrable hashing pool, media detection via `IOCTL_STORAGE_QUERY_PROPERTY`/`StorageDeviceSeekPenaltyProperty` (NVMe/SSD ⇒ higher parallelism; HDD with seek penalty ⇒ serial or near-serial), and prohibits encoding `threads = 8` as universal truth.

## Decision

1. **Decision remains serial.** Only L2/L3 (read+hash, ADR-0004) parallelize, over the already-sorted collection.
2. Enumeration: one task per distinct root volume; no thread swarm on the same MFT.
3. Hashing pool = `Parallel.ForEach` over sorted partition with `MaxDegreeOfParallelism = N`; results drained via ordered channel to the serial coordinator. Nothing decides by completion order.
4. Source of N, in this precedence:
   1. explicit flag `--read-parallelism N` (overrides everything);
   2. persisted user configuration;
   3. media detection;
   4. conservative default `min(ProcessorCount, 4)`.
5. Media detection behind **`IMediaProbe`** interface (contracts.md):

```csharp
public interface IMediaProbe {
    ReadProfile ProbeVolume(string rootPath);
}

public sealed record ReadProfile(bool HasSeekPenalty, int RecommendedParallelism);
```

   Windows-native implementation (P/Invoke `IOCTL_STORAGE_QUERY_PROPERTY` + `STORAGE_DEVICE_SEEK_PENALTY_DESCRIPTOR`) lives isolated; policy mapping: seek penalty ⇒ `RecommendedParallelism = 1..2`; no penalty ⇒ up to `min(2 × ProcessorCount, 16)`. No probe access or unknown volume ⇒ conservative profile. Tests use injected fakes — no test depends on real hardware.
6. Observable, not speculative calibration: §10 telemetry feeds future default adjustment; no tuning without benchmark (§24).
7. Cooperative cancellation (Ctrl+C / GUI close) propagates to all workers; cancellation produces exit 3 (partial) or 1, never a silently truncated report.

## Consequences

- Formal contracts in `docs/contracts.md` (`IMediaProbe`).
- Determinism independent of N: even N=1 or N=32 produce byte-for-byte identical reports (tested).
