# ADR-0011 — Comparador de documentos: abstração agora; texto/markdown/csv no v1; Office diff decidido em card próprio

- **Status:** Aceito
- **Data:** 2026-08-22
- **Decidido por:** Architect (card T01)

## Contexto

§16 manda comparação por tipo de conteúdo atrás de uma abstração `DocumentComparator`, com texto/markdown/csv como casos claros, e Office (.docx/.xlsx/.pptx via Open XML) condicionado à análise técnica e de produto antes de fechar se entra no v1 ou fica para v1.1/Pro (§30, questão A). Este card não decide a questão A — apenas fecha a arquitetura que torna ambas as respostas baratas.

## Decisão

1. Abstração única em `Doctor.Core`: interface `IDocumentComparator` (contratos.md). Seleção por extensão normalizada (case-insensitive); tipo desconhecido ⇒ comparador binário de fallback (aponta os primeiros bytes divergentes).
2. Implementações do **v1**:
   - `TextComparator` — diff textual linha a linha (algoritmo LCS simples; sem dependência externa pesada);
   - `MarkdownComparator` — diff textual + visão estrutural leve (cabeçalhos/blocos), mesma base do textual;
   - `CsvComparator` — alinhamento orientado a linhas/colunas, com contagem de linhas adicionadas/removidas/alteradas;
   - `BinaryFallbackComparator` — offset do primeiro byte divergente.
   Todos produzem o mesmo record de saída `ComparisonResult` (estruturas ordenadas, sem campo incidental de tempo) — a GUI renderiza qualquer formato sem lógica própria (§13).
3. Office semantic diff (**não decidido aqui**): a interface já cobre `docx/xlsx/pptx` via futuros `OfficeXmlComparator`; a decisão v1 vs v1.1/Pro fica para card próprio (questão A do §30), com análise de esforço/valor/risco/diferencial/impacto em prazo exigida pela SPEC. Nenhum stub morto é criado até lá.
4. Comparação lê arquivos somente quando ambos são legíveis e nenhum é placeholder; herda o gate de placeholder do hasher (ADR-0005).
5. Sem dependências externas de diff no v1 (§52): LCS próprio de ~200 linhas é suficiente e auditável.

## Consequências

- Contrato formal em `docs/contratos.md` (`IDocumentComparator`).
- Questão A (Office diff v1 vs Pro) segue em aberto para card dedicado — registrado deliberadamente como decisão pendente, não como omissão.
