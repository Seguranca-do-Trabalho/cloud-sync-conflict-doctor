# ADR-0011 — Document comparator: abstraction now; text/markdown/csv in v1; Office diff decided on its own card

- **Status:** Accepted
- **Date:** 2026-08-22
- **Decided by:** Architect (card T01)

## Context

§16 mandates comparison by content type behind a `DocumentComparator` abstraction, with text/markdown/csv as clear cases, and Office (.docx/.xlsx/.pptx via Open XML) conditioned on technical and product analysis before deciding whether it goes into v1 or stays for v1.1/Pro (§30, question A). This card does not decide question A — it only closes the architecture that makes both answers cheap.

## Decision

1. Single abstraction in `Doctor.Core`: interface `IDocumentComparator` (contracts.md). Selection by normalized extension (case-insensitive); unknown type ⇒ binary fallback comparator (points out the first divergent bytes).
2. **v1** implementations:
   - `TextComparator` — line-by-line textual diff (simple LCS algorithm; no heavy external dependency);
   - `MarkdownComparator` — textual diff + lightweight structural view (headers/blocks), same base as textual;
   - `CsvComparator` — line/column-oriented alignment, with count of added/removed/changed lines;
   - `BinaryFallbackComparator` — offset of first divergent byte.
   All produce the same output record `ComparisonResult` (sorted structures, no incidental time fields) — GUI renders any format without its own logic (§13).
3. Office semantic diff (**not decided here**): the interface already covers `docx/xlsx/pptx` via future `OfficeXmlComparator`; the v1 vs v1.1/Pro decision stays on a dedicated card (question A of §30), with effort/value/risk/differential/impact analysis required by the SPEC. No dead stubs created until then.
4. Comparison reads files only when both are readable and neither is a placeholder; inherits the placeholder gate from the hasher (ADR-0005).
5. No external diff dependencies in v1 (§52): own ~200-line LCS is sufficient and auditable.

## Consequences

- Formal contract in `docs/contracts.md` (`IDocumentComparator`).
- Question A (Office diff v1 vs Pro) remains open for a dedicated card — deliberately recorded as a pending decision, not an omission.
