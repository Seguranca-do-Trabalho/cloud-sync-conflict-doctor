# ADR-0008 — CLI: System.CommandLine com exit codes estáveis

- **Status:** Aceito
- **Data:** 2026-08-22
- **Decidido por:** Architect (card T01)

## Contexto

§14 manda CLI desde o dia um (`conflictdoctor scan <path> [--json] [--quiet]`), modo JSON adequado a scripts/RMM/automação/testes, exit codes documentados e estáveis, sem degradar a UX da GUI. §26/CANAIS.md: operação offline, sem rede.

## Decisão

1. Pacote **`System.CommandLine`** (versão pinada) em `src/Doctor.Cli`; executável `conflictdoctor`.
2. Superfície v1:

```text
conflictdoctor scan <path> [--json] [--quiet] [--output <file>] [--read-parallelism N] [--no-cache]
```

Os comandos de resolução/quarentena (`quarantine apply`, `quarantine restore`) herdam esta mesma tabela de códigos quando existirem — definida agora para não migrar contrato depois.

3. Disciplina de streams: `stdout` reservado ao resultado (`--json` ⇒ JSON puro, zero ruído; sem `--json` ⇒ resumo humano); progresso e diagnósticos ⇒ `stderr`; `--quiet` silencia o progresso, nunca os erros.
4. **Tabela oficial de exit codes** (estável; caso novo entra em código novo, nunca recicla):

| Código | Significado |
|---|---|
| 0 | scan concluído; nenhuma anomalia relevante (nenhuma duplicata/conflito real) |
| 1 | erro operacional (caminho inexistente/inacessível, falha fatal de I/O, uso incorreto de argumentos) |
| 2 | scan concluído; conflitos/duplicatas encontradas |
| 3 | operação parcialmente concluída (alguns arquivos não puderam ser processados; relatório emitido com a lista de erros) |

Precedência: `1` > `3` > `2` > `0`. Erro operacional domina; sem erro, parcial domina; sem parcial, achados dominam.

5. O JSON de `--json` é **exatamente** o schema do ADR-0003 (`report_schema_version = 1`); nenhum formato paralelo de saída.
6. Zero telemetria, zero chamada de rede, zero verificação online (§26); apto a RMM offline (CANAIS.md).

## Consequências

- A GUI consome o mesmo motor e o mesmo schema; a CLI não carrega lógica própria de scan.
- Testes de CLI validam os quatro códigos e a pureza do stdout em modo `--json`.
